About SHMS

What is SHMS?

The Smart Hostel Management System (SHMS) is a web-based application designed to digitize and automate hostel activities such as room allocation, leave management, complaints, fee tracking, mess menu, visitor records and notice management in a single, centralized platform.

System Workflow

A simple step-by-step flow of how the system works.

1. Register / Login

Access the system based on your role.

2. Use Modules

Manage rooms, leaves, complaints, fees, etc.

3. Get Approval

Warden/Admin reviews and takes action.

4. Track & Manage

View updates, history and reports anytime.

Role-Based Access

A dedicated interface for every user with the features they need.

Student Portal

  • Apply for leave
  • Raise complaints
  • View room, fee and mess details

Warden Portal

  • Approve leave requests
  • Manage complaints
  • Monitor students and visitors

Admin Portal

  • Manage students and rooms
  • Handle fee and system data
  • View reports and statistics
